# Finance-Analysis-PowerBI-Dashboard
## Problem Statement

Financial transaction data contains important information about transaction amounts, fees, taxes, customer segments, transaction status, and payment activities. However, analyzing this data in raw or unstructured form can make it difficult to identify trends, compare performance, and understand key business metrics.

The objective of this project is to develop an interactive Power BI dashboard that transforms financial transaction data into meaningful and easy-to-understand visual insights. The dashboard helps analyze transaction performance across different months, states, customer segments, genders, transaction types, and transaction statuses.

The dashboard also provides interactive filters and KPIs to help users quickly monitor important financial metrics and support data-driven decision-making.
